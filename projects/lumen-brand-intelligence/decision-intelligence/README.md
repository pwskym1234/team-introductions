# Lumen 브랜드 분석

소비자 건강 질문이 어떤 안내와 상품 행동으로 이어졌는지 마케터가 직접 탐색하는 작동형 B2B 분석 도구입니다. Amplitude의 정보 밀도와 분석 문법을 참고하되, 건강 영역에 필요한 안전 결과·상품 적격성·개인정보 경계를 제품의 중심에 뒀습니다.

## 구현된 제품

- 홈: 질문 수, 정보 확인 완료율, 적격 상품 노출률, 근거 열람률, 추세와 우선 확인 변화
- 질문 분석: 측정값과 분류 기준을 바꾸는 쿼리 빌더, 시계열, 상세 표
- 전환: 실제 이벤트 순서를 보존한 전환 계산, 순서 규칙, 곡선형 퍼널, 단계별 드릴다운
- 여정: 질문 목적→정보 확인→최종 안내→후속 행동을 잇는 경로 지도와 고객 그룹 저장
- 고객 그룹: 사람이 읽는 AND/OR 규칙, 예상 규모, 저장 그룹 비교
- 상품: 질문×상품 후보·적격·제외·검토·노출·근거 열람·상세 이동 원장
- 질문 기록: 익명 질문 한 건의 실제 이벤트 시각·순서·버전·결정 이유
- 인사이트: 관찰, 영향을 준 집단, 해석 한계, 다음 분석을 분리한 변화 목록
- 데이터: 이벤트·속성 사전과 브랜드 화면에 허용/금지된 개인정보 경계
- 판단 엔진: 비개발자용 시나리오 실행, 6가지 판단, 불확실성, 거짓 경보, hard filter, 감사 결과

## 데이터와 상호작용

고정 seed로 익명 사용자 6,200명, 질문 12,400건, 순서·시각이 있는 합성 이벤트 228,075건을 만듭니다. 기간 프리셋, 직접 날짜 범위, 이전 기간/전년 비교, 일·주 간격, 기본 사용자군과 AND/OR 세부 조건이 실제 원장 재계산에 연결됩니다.

모든 데이터는 합성입니다. 브랜드 화면에는 질문 원문, 약명·용량, 개인 건강 원시값을 저장하지 않습니다.

## 실행과 검증

Node.js `>=22.13.0`이 필요합니다.

```bash
npm install
npm run dev
npm run lint
npm test
```

`npm test`는 production build 뒤 브랜드 분석과 엔진 설명 두 경로의 서버 렌더, 합성 원장, 기간·조건·퍼널·여정 기능 정의를 확인합니다.

배포 화면: [Lumen 브랜드 분석](https://lumen-brand-analytics-20261003.snu-chatgpt-5678.chatgpt.site/?view=overview&range=30)

## 주요 파일

- `app/ProductApp.tsx`: 전체 제품 셸과 9개 분석 화면
- `app/components/AnalyticsUI.tsx`: 기간·비교 메뉴, custom popover, 곡선 퍼널, 시계열, 여정 지도
- `app/lib/analytics.ts`: 합성 이벤트 원장, 데이터 사전, 퍼널·시계열·여정·상품·KPI 쿼리
- `app/engine-guide/EngineGuideApp.tsx`: 추천 엔진을 쉬운 말과 실예로 설명하는 별도 웹페이지
- `app/globals.css`: 고밀도 B2B 제품 UI와 반응형 레이아웃
- `docs/Amplitude_UI_System_Complete_Audit_v3.md`: Amplitude 공식 자료 기반 UI 시스템 정밀 분석, 현재 화면 감사, 개편 기준
- `../ENGINE_AUDIT_AND_UPGRADE.md`: 엔진 56→82점 감사, Claude 코드 비교, 33개 테스트, 운영 전 과제

실제 엔진은 인접한 `../decision-engine/`에 있습니다. Node `crypto`와 개인정보 경계를 포함하므로 브라우저에 직접 번들하지 않고 서버에서 실행한 뒤 허용된 집계 이벤트만 이 도구로 전달하는 구조가 적합합니다.
